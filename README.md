# 맥박 노트

맥박·운동·수면 기록 웹앱 (아이폰 홈 화면 앱 지원)

| 탭 | 기능 |
|---|---|
| 맥박 | 15초 세기로 맥박 기록, 최근 기록, 안정 시 맥박 참고 자료, 애니메이션 |
| 운동 | 3·6·9 운동 루틴, 금력·유산소 기록 추가, 최근 기록 |
| 프로필 | 나이·성별·키·몸무게 입력, BMI 표시, 사진 관리 |

- 다크/라이트/자동 테마, 한국어/English 전환
- 기록은 이 기기(localStorage)에만 저장됩니다. 로그인 없이도 모든 기능을 사용할 수 있어요.
- 참고·교육용이며 의료 상담을 대신하지 않아요.
